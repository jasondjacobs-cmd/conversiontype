How to convert a percentage to a ratio

Write the percentage as a ratio to 100, then reduce it. For 75%, start with 75:100 and reduce by 25 to get 3:4.

Examples

  • 25% = 1:4
  • 50% = 1:2
  • 75% = 3:4
  • 20% = 1:5
