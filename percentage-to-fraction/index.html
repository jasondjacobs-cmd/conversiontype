How to convert a percentage to a fraction

Write the percentage over 100, remove decimals if needed, then reduce. For 75%, 75/100 becomes 3/4.

Formula

Write the percentage over 100, remove decimals if needed, then reduce. For 75%, 75/100 becomes 3/4.

Examples

  • 75% = 3/4
  • 1/2 = 0.5
  • 1/4 = 25%
  • 50% = 1/2
