How to solve a missing ratio value

Set the ratios equal and cross-multiply. This calculator treats the equation as a:b = c:x and solves for x.

Formula

x = (b × c) ÷ a. For 2:3 = 4:x, x = (3 × 4) ÷ 2 = 6.

Examples

  • 2:3 = 4:6
  • 3:5 = 9:15
  • 4:7 = 12:21
  • 5:8 = 15:24
