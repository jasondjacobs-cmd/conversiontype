How to solve a missing ratio value

Equivalent ratios keep the same relationship. If a:b = c:x, multiply b by c and divide by a to find x.

Examples

  • 2:3 = 4:6
  • 3:5 = 12:20
  • 4:7 = 8:14
  • 5:2 = 15:6
