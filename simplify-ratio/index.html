How to simplify a ratio

Find the greatest common divisor of both values. Divide each side by that divisor. The resulting values form the simplest equivalent ratio.

Formula

Simplified ratio = (a ÷ GCD):(b ÷ GCD). For 24:36, the GCD is 12, so the answer is 2:3.

Examples

  • 24:36 = 2:3
  • 10:15 = 2:3
  • 16:9 = 16:9
  • 100:25 = 4:1
